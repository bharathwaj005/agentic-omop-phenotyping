# Agentic OMOP Phenotyping

Official code, benchmark specifications, and reproducible evaluation manifests for the research manuscript:

**"How Faithfully Do Agentic AI Systems Generate OMOP Cohort Definitions? A Controlled, Low-Resource Evaluation of Multi-Agent Phenotyping"**

Submitted to the *Journal of Biomedical Informatics* Special Issue on *Agentic AI for Real-World Evidence Life Cycle Support*.

## Repository Structure
- `src/`: Modular multi-agent phenotyping pipeline (Planner, Concept Resolver, Cohort Builder, Deterministic Validator, Critic).
- `tasks/`: Benchmark specifications for V5.3 General track (T01–T20) and Neurological track (N01–N12).
- `results/`: Official execution traces, dual-denominator scoring manifests, and statistical outputs.
- `manuscript/`: Complete manuscript chapters and cryptographic verification manifests.
